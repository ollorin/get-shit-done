## Decision impact (05 D1 / D2 / D4 / D5)

- D1: (a) works; add the env var as a belt-and-braces option only if children (executors) idle >5 min. (b) works as designed, parallel + blocking, zero wait-turns, but pass `run_in_background: false` explicitly. Optional enforcement: SubagentStop gate on `SUMMARY.md` with absolute path and retry cap.
- D2: the product already blocks leading `sleep N>=25` in foreground Bash; ship the hook for the other wait idioms. Per-agent frontmatter hooks avoid global settings (trust prerequisite).
- D4: MEMORY.md and user CLAUDE.md reach subagents (confirmed). `omitClaudeMd` does not stop path-scoped rule loading. `@` is not expanded in agent bodies. Verify budgets via transcript `instructions`/`nested_memory` attachments, not the InstructionsLoaded hook.
- D5: `Agent` hook input has `subagent_type` and a `model` only when explicitly passed; deny + reason reaches the caller. Missing `model` must be resolved against frontmatter. `agent_type`/`agent_id` identify nested spawners.
