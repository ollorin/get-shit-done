## (5) Current restart procedure (from memory notes)

- Rule (CEO 2026-10-31, `feedback_disk_threshold_5gi.md`): restart OrbStack or serve only when free disk < ~3 GiB, or when docker or a bucket run stalls. Swap is never a trigger. Never mid-Charlotte. One restart owner.
